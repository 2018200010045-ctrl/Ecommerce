ELECTROMART - PHASE 1
=====================

This package is a responsive electronics e-commerce FRONTEND demo.

Included:
- Product catalogue
- Search and category filtering
- Shopping cart with localStorage
- Checkout form
- bKash / Nagad / Rocket / Visa-Mastercard / Cash on Delivery choices
- Facebook Page button
- Mobile responsive layout

IMPORTANT:
The checkout and payment options are UI/demo only. Real orders and online payments require a secure backend, database, merchant accounts, server-side transaction verification and payment callbacks/webhooks.

NEXT PHASE CAN ADD:
1. Admin dashboard
2. MySQL database
3. Product/stock management
4. Customer and order management
5. Real payment gateway integration (for example SSLCOMMERZ or another approved gateway)
6. Facebook/Meta integration and tracking
7. Order status and notifications

To preview: open index.html in a browser.
